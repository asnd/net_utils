# GitLab CI/CD Quick Reference

## Pipeline Overview
```
PREPARE → TEST (5 jobs) → BUILD (4 platforms) → PACKAGE → RELEASE
  30s       2-4 min          3-5 min            1 min      tags only
```

## Jobs at a Glance

| Stage | Job | Status | Duration | Blocks Pipeline |
|-------|-----|--------|----------|-----------------|
| prepare | download-dependencies | Required | 30s | Yes |
| test | test:unit | Required | 1-2m | Yes |
| test | test:vet | Required | 30s | Yes |
| test | test:fmt | Required | 10s | Yes |
| test | test:lint | Optional | 2-3m | No |
| test | test:security | Optional | 1-2m | No |
| build | build:linux-x64 | Required | 1m | Yes |
| build | build:windows-x64 | Optional | 2-3m | No |
| build | build:macos-arm64 | Optional | 1-2m | No |
| build | build:macos-x64 | Manual | 1-2m | No |
| package | package:all | Auto | 1m | master/main/tags |
| package | release | Auto | 30s | tags only |

## Quick Commands

### Run full pipeline
```bash
git push origin master
```

### Create release
```bash
git tag v1.0.0
git push origin v1.0.0
```

### Fix formatting
```bash
gofmt -w .
```

### Run tests locally
```bash
go test -v -race ./...
go vet ./...
```

### Build locally (Linux)
```bash
go build -o pcap_stripper pcap_stripper.go
```

## Platform Support

| Platform | Status | Notes |
|----------|--------|-------|
| Linux x64 | ✅ Full | Primary platform |
| Windows x64 | ⚠️ Cross | Requires Npcap |
| macOS ARM64 | ⚠️ Cross | May need signing |
| macOS x64 | ⚠️ Manual | On-demand only |

## Troubleshooting

| Issue | Solution |
|-------|----------|
| Tests fail | Fix code, push again |
| Lint warnings | `gofmt -w .` |
| Build fails | Check job logs |
| macOS build fails | Expected (cross-compile) |
| Windows build fails | Expected (no WinPcap SDK) |

## Environment Variables

```bash
PACKAGE_NAME=pcap_stripper
CGO_ENABLED=1
Version=${CI_COMMIT_TAG:-dev}
GitCommit=${CI_COMMIT_SHA:0:8}
```
